# СИЛА И ЧЕСТЬ / TEE — съёмочный план и ТЗ

Документ для двух сценариев:
**А)** Никита присылает свои фото → пересобираем серию и ролик с ним (2–3 часа работы);
**Б)** реальная съёмка с фотографом по этой раскадровке → пересобираем ролик из живых кадров тем же скриптом.

Раскадровка, свет, реквизит и позы уже отработаны на черновой серии (`sila-i-chest-01…06.jpg`) — это и есть визуальный референс для каждой сцены.

---

## Что нужно от Никиты (сценарий А)

Минимум **6–10 фото**, чем разнообразнее — тем точнее сходство:

| # | Что | Зачем |
|---|---|---|
| 1 | Анфас, нейтральное лицо, ровный дневной свет, без очков/кепки | база лица |
| 2 | Профиль слева и справа | кадр «Спина» (голова в профиль) и крыша |
| 3 | 3/4 поворот, лёгкий прищур / серьёзное выражение | ночь, свои |
| 4 | Улыбка или полуулыбка | на будущее, для «мягких» кадров рассылки |
| 5 | В полный рост в тёмной футболке | пропорции тела, посадка футболки |
| 6 | Руки крупно (кисти, предплечья) | тату / их отсутствие должны совпадать |
| 7 | Со спины, шея и затылок | кадр «Спина» |
| 8 | Любые 2–3 живых кадра из тренировки / с улицы | манера держаться, реальная мимика |

Требования к фото: без сильных фильтров, резкие, лицо не меньше ~600 px по высоте, желательно за последний год. Формат любой (JPG/HEIC/PNG).

Плюс письменное подтверждение в любой форме («ок, используйте мои фото для генерации визуалов бренда»).

## Сцены (для А и Б)

Референс для каждой — соответствующий файл черновой серии.

### 01 — НОЧЬ. ФОНАРИ. `→ sila-i-chest-01-gelik-night.jpg`
- **Локация:** узкая улица после дождя, тёплые натриевые фонари + холодная вывеска, пар/дым в глубине.
- **Реквизит:** чёрный внедорожник с включённым ближним светом сзади (не в фокусе).
- **Поза:** фронт, вес на одну ногу, руки в карманах карго, взгляд чуть мимо камеры.
- **Оптика/свет:** 85 мм, f/1.8–2.0, ключевой свет — фонарь сверху-сбоку, контровой от фар.
- **Задача кадра:** главный кадр карточки товара. Принт спереди — резкий, читается целиком.

### 02 — СВОИ. `→ sila-i-chest-02-crew.jpg`
- **Локация:** под бетонной эстакадой, одна оранжевая лампа сверху, мокрый асфальт.
- **Люди:** Никита впереди без маски; 4–5 человек в чёрных балаклавах и худи за спиной, **не в фокусе**, руки опущены. Без оружия, без жестов, без символики — только строй.
- **Поза:** руки скрещены, прямой взгляд в камеру.
- **Оптика:** 50 мм, f/2.8, симметрия по центру.

### 03 — ЖЕЛЕЗО. `→ sila-i-chest-03-gym.jpg`
- **Локация:** старая качалка: кирпич, ржавые блины, силовая рама.
- **Свет:** одна тёплая лампа сверху, пыль/мел в луче.
- **Поза:** сидит на скамье между подходами, предплечья на коленях, руки в меле, пот.
- **Оптика:** 50 мм, f/2.0. Принт спереди читается.

### 04 — СПИНА. ТУРНИК. `→ sila-i-chest-04-boxing-back.jpg` ★ единственный кадр с задним принтом
- **Локация:** тёмный индустриальный зал, чёрная силовая рама с турником, зеркала и ряды холодных ламп в глубине.
- **Поза:** верхняя точка подтягивания широким хватом, голова чуть опущена между плеч, спина максимально раскрыта. Камера строго сзади на уровне груди.
- **Оптика:** 50 мм, f/2.0–2.8. **Меч и монограмма ВВ — резкие, по центру позвоночника**, футболка натянута спиной, без складок.
- В карточке товара идёт вторым фото.

### 05 — ГОРОД. СИНИЙ ЧАС. `→ sila-i-chest-05-roof.jpg`
- **Локация:** крыша панельного дома, антенна, огни города за спиной. Снимать за 20–30 минут после заката.
- **Поза:** почти фронт к камере, одна рука в кармане, спокойный взгляд в объектив. Без агрессии.
- **Оптика:** 35–50 мм, f/2.8. Палитра — глубокий синий + тёплый янтарь окон.

### 06 — ТОВАР. РАСКЛАДКА. `→ sila-i-chest-06-flatlay.jpg`
- **Что:** две футболки на бетоне, слева перед, справа спина, вид строго сверху.
- **Свет:** мягкий рассеянный дневной, без жёстких теней.
- **Задача:** карточка без человека; должна быть видна фактура хлопка и чистый край принта.

## Технические требования к результату

- Вертикаль **4:5** для карточек и ленты, **9:16** — для сторис/ролика (снимать с запасом по верху и низу).
- Минимум 2000 px по длинной стороне, JPG качество ≥ 90 или RAW.
- На каждом кадре с человеком принт спереди или сзади должен читаться без увеличения.
- Никаких сторонних логотипов в кадре (машина — заклеить/размыть шильдик, одежда без брендов).

## Пересборка после съёмки

```bash
# 1) положить финальные файлы под теми же именами в sila-i-chest/
#    sila-i-chest-01-gelik-night.jpg … sila-i-chest-06-flatlay.jpg
# 2) ролик
cd sila-i-chest && python3 video/make_video.py
# 3) ассеты бота/Mini App (пережимает до 1280 px и кладёт в miniapp/assets/sila-i-chest/)
python3 - <<'EOF'
from PIL import Image; from pathlib import Path
src, dst = Path("sila-i-chest"), Path("audit-repo/miniapp/assets/sila-i-chest")
for s, d in {"01-gelik-night":"front-night","04-boxing-back":"back-boxing","06-flatlay":"flatlay","02-crew":"crew","03-gym":"gym","05-roof":"roof"}.items():
    im = Image.open(src / f"sila-i-chest-{s}.jpg").convert("RGB"); im.thumbnail((1280,1280), Image.LANCZOS)
    im.save(dst / f"{d}.jpg", quality=82, optimize=True, progressive=True)
EOF
```

Каталог (`catalog.json`) и Mini App уже ссылаются на эти имена — менять ничего не нужно.
